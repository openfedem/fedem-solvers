Detailed Description

Fortran wrapper for the FFaTensorTransforms methods.

This file contains the implementation of the following Fortran wrappers of the FFaTensorTransforms module:

  • ffatensortransformsinterface::vonmises
  • ffatensortransformsinterface::princval
  • ffatensortransformsinterface::maxshearvalue
  • ffatensortransformsinterface::maxshear
  • ffatensortransformsinterface::tratensor
  • ffatensortransformsinterface::trainertia

No further documentation is provided here. The wrappers are documented in the FFaTensorTransformsInterface.f90 file.
